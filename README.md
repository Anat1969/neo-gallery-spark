# ART-AI גלריה

הגלריה הדיגיטלית של ענת: קטגוריות, גלריות, חדרים ויצירות AI.

- נתונים: Supabase, פרויקט CULTURA-GH, טבלאות בקידומת `neo_`.
- פריסה: Vercel, ענף main.
- פיתוח מקומי: `npm install`, ואז `npm run dev`.
- בדיקות: `npm run build`, `npm test`.

פרטים מלאים ב-`CLAUDE.md` ובהיסטוריית ההגירה ב-`docs/MIGRATION.md`.
